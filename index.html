3. Overview of printer.cfg

Architecture

In Klipper 3D printer firmware, printer.cfg serves as the primary configuration hub. Rather than maintaining a single monolithic configuration file containing thousands of lines, standard practice in Voron builds is to split the configuration modularly using [include ...] statements.

This modular structure simplifies troubleshooting, keeps pin assignments localized, and makes updating individual sub-systems (such as toolhead CAN boards, Nevermore filter macros, or Neopixels) clean and maintainable.

4. Configuration Modular Breakdown

Config Files
[include mainsail.cfg]
Provides base macro definitions, state tracking variables, and communication hooks for Mainsail OS.
  • Base macros: PAUSE, RESUME, CANCEL_PRINT
  • Display & system state definitions
[include canbus-rp2040.cfg]
Configures the BTT EBB SB2209 CAN toolhead board operating via CAN bus.
  • CAN bus canbus_uuid: 4cc248f5b9f1
  • Hotend PT1000 sensor on gpio27 with 4.7kΩ pull-up
  • ADXL345 accelerometer for Input Shaping
  • Extruder TMC2209 on gpio20 at 0.60A
[include TMC2209.cfg]
Defines UART communication and driver parameters for all 6 mainboard stepper slots.
  • Motors 1-2: Stepper X/Y (1.000A run_current)
  • Motors 3-6: Stepper Z0, Z1, Z2, Z3 (0.800A run_current)
  • SpreadCycle mode enabled (stealthchop_threshold: 0)
[include motors.cfg]
Defines motion limits, rotation distances, and microstepping for all axes.
  • X/Y position_max: 350 mm, 32 microsteps
  • Z rotation_distance: 40, gear_ratio: 80:16
  • Voron TAP virtual endstop on stepper_z
[include tap.cfg]
Configures the Voron TAP nozzle-based optical probe and Quad Gantry Leveling (QGL).
  • Probe pin: !EBBCan:gpio22
  • 150°C probe safety macro (prevents bed surface damage)
  • Quad Gantry Leveling points for 350mm build
[include macros.cfg]
User G-code routines and print cycle sequences.
  • PRINT_START (heatsoak, QGL, adaptive bed mesh, purge line)
  • PRINT_END (retract, park, cool down, disable steppers)
  • M600 filament change macro
[include nevermore.cfg]
Controls the Nevermore active carbon recirculating air filter.
  • Fan generic BedFans on pin PF7 (FAN0 header)
  • Automated heating monitoring loop and speed control
  • Integrated KNOMI status hooks for bed heating
[include fans.cfg]
Mainboard electronics enclosure cooling and bed heater configuration.
  • Electronics fans on M8P pins PF8 and PA4
  • Exhaust fan on pin PA6
  • AC bed heater on SSR pin PF5, thermistor on PB1
[include KNOMI.cfg]
Configures the BTT KNOMI status display on the toolhead.
  • Display state variables (homing, probing, QGL, heating)
  • Macro wrappers for G28, M109, and Quad Gantry Leveling
[include lights.cfg]
Stealthburner Neopixel harness and enclosure lighting control.
  • Toolhead Neopixel chain on EBBCan:gpio16 (3 LEDs, GRBW)
  • Status macros (STATUS_HOMING, STATUS_HEATING, STATUS_PRINTING)
  • Chamber caselight output on PA3
